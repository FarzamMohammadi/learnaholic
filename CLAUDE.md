# Learnaholic

Knowledge repository: structured notes, algorithm implementations, coding problems, curated articles, research, and learning roadmaps.

## Structure

11 top-level sections, each with its own README.md. See root [README.md](./README.md) for the full directory reference.

## Rules

- Read [repo-guidelines.md](./repo-guidelines.md) before any changes
- Never modify technical content (algorithms, research docs, code, articles) without explicit request
- Section READMEs follow a lightweight template: title, one-liner, contents table
- Link collections use `reading-list.md` as their filename
- `research/` has its own [CLAUDE.md](./research/CLAUDE.md), doc-refiner agent, and templates -- defer to those when working in that section

## Conventions

- Files and directories: `lowercase-hyphenated` (language-specific exceptions in repo-guidelines.md)
- Documentation tone: reader's time is sacred, active voice, no fluff, every sentence transfers knowledge
- Numbered series: `00-index.md`, `01-topic.md`, `02-topic.md`
- C# projects: PascalCase directories and files
- C++ files: PascalCase matching class names
